# 公开测试与发布检查

本目录是与自用版分离的公开候选版。没有发布 GitHub 仓库、上传文件或签名安装包；这些动作需由维护者确认。

已移除：游戏页面、Riot／LCU／英雄数据提供器、游戏设置、游戏模型提示词及归档导入字段。四页主线、全部 12 种主题、明暗模式、文学工作台、宽复盘编辑和备份保留。

内容策略：公开文学首版只打包已核对的《飞鸟集》24 则；其他作家的旧节选未作为已审完素材发布。用户提供的鸢尾花诗暂不发布，直到作者明确同意公开分发；私人版原文不变。微风徐徐诗为 AI 辅助原创，明确非画家语录。代码 MIT 与第三方艺术授权分开。

## 发布前

1. `npm ci`、`npm test`、`npm run test:ui`、`npm run audit:release`。
2. 检查所有打包素材的来源及所在法域授权，特别是建筑／雕塑摄影；项目校验不能取代法律判断。
3. 手动测试真实 API（自己的低成本请求）、离线、休眠后计时、不同 Windows 用户、多显示器与高 DPI。自动测试不使用付费密钥，不声称已测真实服务。
4. 在另一台干净 Windows 电脑试跑。当前没有安装器、自动更新或代码签名，不宣传已完成这些功能。
5. 分享源码白名单目录，排除 `.env`、`*.enc`、用户数据、备份、私人背景、测试产物、`node_modules`。扫描不能发现所有未知秘密，维护者仍要复核。
6. 若要二进制安装包，后续再配置打包工具、第三方许可附带、签名和版本发布流程。

## 已知限制

联网新视觉作品受 Commons 可用性和元数据影响，校验失败宁可不展示；文学库首版较小。没有自动 AI 换主题、通用模型网关、账号云同步、自动迁移私人备份。AI 背景分析可能错误，不能替代馆藏来源。

界面主题与交互有公开试用价值，但代码由多次迭代叠加，`index.html` 仍较大。下一阶段优先拆分页面／状态模块、完善无障碍与内容审核流程，而不是继续堆功能。建议以“有设计辨识度的个人学习工具，公开测试版”分享，诚实列出边界。
