# 开源候选版交接 · 2026-09-15

## 用户决定与目录

用户确认代码采用 MIT。这个候选目录与 `3566-app` 私人版完全分开，未覆盖私人版代码、背景或用户记录；不读取或自动迁移私人版用户数据。公开桌面数据位于 `%APPDATA%\3566-open-source`。

用户尚未明确授权鸢尾花诗的公开分发，因此候选版不收录该诗；私人版保留。其美学价值与公开授权是两件事。

## 完成内容

- 仅四个顶层页面：今日、复盘、归档、彩蛋。游戏实现、提供器、密钥设置、IPC、模型提示词与归档字段实际移除，而非只隐藏按钮。
- 十二种主题与白天／黑夜模式保留，修正油画主题中新设置手册的文字对比。
- 六步首次导览，可跳过、记住完成状态、重新观看；每组设置有解释，完整手册支持搜索与跳转。
- 开屏背景原生文件选择，支持 PNG／JPG／WebP，体积及像素校验；本机复制、可恢复重置，不改原图、不进 JSON 备份。
- API 手册写明申请入口、实际调用路径、模型选择、Key 保存与清除、环境变量回退、隐私、费用和故障解释。保存密钥不等同于网络连通性测试。
- 私人默认任务改为通用任务；未核对名人语录改为应用原创离线短句；文学首版只保留已核对的 24 则《飞鸟集》与应用参考译文。
- 素材许可严格匹配，排除 NC／ND 许可误判；来源文字不通过活跃 HTML 插入，媒体域名受限，许可入口保留。
- README、MIT、内容来源、隐私安全、发布检查、白名单扫描及干净源码 ZIP 工具提供。

真实账户 API 权限、地区和低成本问答；另一台干净 Windows、高 DPI、休眠后计时；艺术复制图与发布法域授权复核。未创建安装器、签名、自动更新或 GitHub 发布。这个版本应标注为 0.1.0 公开测试候选版，不能宣传上述事项已经完成。

## 维护命令

```powershell
npm ci
npm start
npm test
npm run test:ui
npm run audit:release
npm run build:browser
npm run package:source
```

最后一项会在目录外生成带时间戳的源码 ZIP，先扫描，不覆盖已有文件。若需要改主题、扩充文学或接入其他模型，先更新对应来源与隐私说明，不默认把个人素材一起公开。
