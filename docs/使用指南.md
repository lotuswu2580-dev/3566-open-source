# 从第一次打开到自己的书桌

首次导览可随时跳过，设置顶部可重新观看。每组设置末尾有“使用说明”，完整手册支持搜索“API”“开屏”“备份”等关键词。

## 四个页面

今日：固定待办决定打卡与每日仪式解锁，临时待办不增加解锁门槛。番茄钟默认专注 25 分钟；开始／暂停控制当前计时，重置回到当前阶段起点，跳过切换阶段。关闭应用不会在后台持续计时。

复盘：写下学到的东西，点击“记录并排期”或 Ctrl + Enter。第 1、2、4、7、15、30 天出现复习提示；勾选只表示这次已复习，不是记忆效果保证。长文可拖动输入框右下角调整高度；未提交文字也保存在本机草稿中。

归档：视觉评论按绘画、建筑、雕塑、动效分类，文学仿写与看过的鉴赏文本分别归档。可搜索、加标签、展开与折叠，视觉记录可追加后续想法。文学模块不增加评论。学习复习笔记仍在复盘页。积累两周后会邀请重看旧记录，不要求连续打卡。

彩蛋：视觉作品从精确绑定的 Wikimedia Commons 文件页实时获取，校验作者元数据与许可，附原始来源；失败不显示仿画替代。文学想象给意象或背景，不限定诗／散文等体裁，可让模型先提问、指出弱点或给替代写法，建议不会覆盖原稿。鉴赏外文保留双语；首版为 24 则《飞鸟集》，中文是应用参考译文而不是出版译本。

## 每个设置选项

| 选项 | 用途与生效方式 |
| --- | --- |
| 油画：鸢尾花／微风徐徐 | 完整画作、深色展墙、聚焦灯；点击画框打开大图与馆藏来源。右下角纯画／图文隐藏或恢复上方文字；两间展室共用偏好。 |
| 色场／柔幕／构成 | 分别偏鲜明色块、柔和低饱和、平面构成；不改变任何内容。 |
| 柔光／书页／跃纸／静域／轨道／格序／序白 | 七种日常界面；随时预览，立即保存。静域适合长文，格序偏黑白网格，序白偏编辑留白。 |
| 白天／黑夜 | 手动切换，独立于主题；不自动随日落切换。油画展墙仍深色。 |
| 小／标准／大／特大 | 调整阅读密度；大字号需更多滚动，不修改文字。 |
| 开屏开启／关闭 | 只影响启动时展示图片，不改变应用主题；没选图片则不展示。 |
| 选择图片／重置开屏图 | 见下文；下次启动生效。重置保留上一张图供人工恢复。 |
| Kimi K3／Google Gemini | 决定顾问和文学评估使用的服务商；需各自密钥。 |
| 顾问发送当前图片：开／关 | 默认关，仅 Gemini 生效；发送当前已核验的视觉素材，不发送开屏图。 |
| K3 Key 保存／清除 | 保存加密密钥，清空密码输入框；清除本机密钥，不能删除环境变量。 |
| Gemini Key 保存／清除 | 同上，独立于 K3。 |
| Gemini 模型 ID 保存 | 默认 `gemini-3.8-flash`，修改输入后必须点击该行保存；以账户可用模型为准。 |
| 每日仪式／自由浏览 | 仪式需完成未隐藏固定任务后解锁新作品；自由浏览随时打开。不删除打卡、评论或归档。文学仿写与历史始终开放。 |
| 每日固定任务模板 | 每行一项，1–20 项，每项最多 160 字；点击保存，从明日起生效，不重写今天与旧记录。 |
| 重新观看新人引导／设置手册 | 随时补看，不重置个人记录。 |

动画遵循系统“减少动态效果”设置。应用并未承诺固定帧数，也没有尚未实现的每日 AI 自动换画功能。

## 怎样更换开屏背景

设置 → 开屏图 → 选择图片。支持 PNG、JPG、JPEG、WebP，文件和转换后的图片最多 16 MB，最多 2400 万像素。推荐约 16:9 横图；适配窗口可能裁切边缘。选择成功会同时开启开屏，重启后展示，可点击跳过。

桌面程序把图片转换为 PNG，复制到 `%APPDATA%\3566-open-source\custom-splash.png`；不修改选择的原文件，不上传模型，不进入 JSON 备份。上一张保留为 `custom-splash.previous.png`。重置会清除当前启动图，并保留上一张供人工恢复。要找回，可再次用选择图片选这份文件。

“换开屏”和“换油画主题”是两件事。主题画作是项目附带资源；自动抓取新主题并让 AI 匹配色彩尚未实现。开发者若替换 `assets/themes`，也要更新馆藏信息、来源、授权和替代文本，不能仅把任意图片冒称原画。

## API 从申请到真正调取

不配置 API 仍能完成待办、专注、复习、归档与本地文学鉴赏。开源免费不意味着服务商 API 免费，不要粘贴别人的密钥或敏感原稿。

### Kimi Code K3

1. 在 [Kimi Code 官方文档](https://www.kimi.com/code/docs/) 对应账户确认 API 权限，申请自己的 API Key。普通 Moonshot 开放平台 Key 与本程序 Kimi Code 端点并非可任意混用。
2. 设置 → K3 API → 粘贴 → 保存。程序安全加密保存后清空输入框。
3. 审美顾问模型选择 Kimi K3。
4. 彩蛋 → 视觉作品 → 顾问，发送一个简短问题；或文学仿写 → 输入原稿 → 评估。这一步才真正请求网络、可能计费。保存密钥本身不是连通性测试。

固定端点 `POST https://api.kimi.com/coding/v1/chat/completions`，模型 `k3`，`Authorization: Bearer`。当前不提供自定义 Base URL／代理／OpenAI Key 输入。

### Google Gemini

1. 按 [Google 官方密钥说明](https://ai.google.dev/gemini-api/docs/api-key) 在 AI Studio 创建 Key，确认地区、项目、权限、配额和计费。
2. 设置 → Gemini API → 粘贴 → 保存，然后选择 Google Gemini。
3. 模型 ID 默认 `gemini-3.8-flash`；依据 [官方模型列表](https://ai.google.dev/gemini-api/docs/models) 和账户权限填写其他兼容 generateContent 的文本／视觉模型，再点击模型行保存。不能把 Live、图像生成等专用模型随意填进来。
4. 发送简短问题验证。需要模型看当前视觉作品时，再开启“顾问发送当前图片”；下载失败会提示并降级为文字。

固定端点 `https://generativelanguage.googleapis.com/v1beta/models/<model>:generateContent`，通过 `x-goog-api-key` 鉴权。不会把开屏图片上传。

### 状态与故障

“已配置”＝本机或环境变量有 Key，不保证 Key 有效。401／403 检查密钥来源、权限与过期；404 检查模型 ID；429 检查额度／速率；超时检查网络。不会自动重复付费请求。AI 给的设计解释、背景或文学修改需要你自行判断，史实回到原始来源核验。

开发可在启动进程环境提供 `K3_API_KEY` 或 `GEMINI_API_KEY`，已保存密钥优先。清除按钮只删本机加密文件；环境变量需在系统或启动终端自行移除。若系统安全加密不可用，界面会报保存失败，程序不回退明文。不要把 Key 写进源码、截图、Git 或问题反馈。

## 记录与备份：每个按钮

- 导出完整 JSON：下载可恢复的文字、历史和设置，不含 API 密钥、开屏图片、可重新获取的图像缓存。
- 选择恢复文件：只先预览。默认“仅补充缺失记录”保留同名本机记录；“用文件替换同名记录”是整条替换，不删除文件里未包含的记录。
- 确认策略并恢复：先创建当前独立副本再恢复；成功后需重新载入。不要在恢复后仍用旧页面继续编辑。
- 重试未保存内容：重试本机写入失败；仍失败先导出副本，不要关闭。
- 导出故障副本：保留原始损坏数据和未保存内容，供人工恢复；不是普通可直接导入备份。
- 立即独立备份：在用户目录 `notebook-backups` 写文件；查看本机备份：点一份旧快照进入恢复预览。

桌面改动后自动备份，分组保留最近 12 份自动、6 份手动和 6 份恢复前副本；没有云同步。公开版拒绝包含游戏等已移除字段的私人版备份，不能直接迁移；私人版原数据保持原样。浏览器预览仅有浏览器本地记录及手动下载，不共享桌面数据。
