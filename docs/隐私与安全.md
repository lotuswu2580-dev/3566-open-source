# 隐私与安全边界

应用没有账号、开发者遥测或云同步。本地优先不等于完全离线：每日短句、Commons 作品以及你主动发起的模型请求使用网络。

## 留在本机

待办、复习、草稿、评论、文学版本、设置保存在 Electron 的本机浏览器存储；独立 JSON 快照保存在 `%APPDATA%\3566-open-source\notebook-backups`。开屏图复制到同一用户目录，不触碰选择的原文件。公开版不会读取私人版数据。

K3／Gemini 密钥由 safeStorage 系统加密落盘，不返回到页面、源码或 JSON 备份。不能安全加密时拒绝保存。本机加密不等于能防御已控制电脑的恶意程序，也不保证备份到别的电脑后可解密；换电脑要自己重新配置 Key。

## 网络去向

| 操作 | 服务与内容 |
| --- | --- |
| 每日短句 | `v1.hitokoto.cn`，普通短句请求，服务能看到网络地址；来源按返回值标注，不保证逐条校对。 |
| 新视觉作品 | `commons.wikimedia.org` 元数据、`upload.wikimedia.org` 原图或缩略图，服务能看到请求与 IP。 |
| K3 主动提问／文学评估 | `api.kimi.com`，问题、作品来源信息及最近对话，或文学背景和原稿。 |
| Gemini 主动提问／文学评估 | `generativelanguage.googleapis.com`，相同文本；仅开启发送图片时附当前已核验视觉素材。 |
| 点击来源链接 | 在系统浏览器打开受限 HTTPS 来源网站，由该网站处理请求。 |

不会自动把整个归档或开屏图发给模型。Key 保存不触发真实问答。模型服务商权限、地区、费用与数据处理规则由其自行决定；勿提交机密与未获授权的内容。

## 实现边界

渲染器关闭 Node 集成，启用上下文隔离；IPC 仅接受指定本地页面的本窗口主框架；外部导航被阻断。外部链接仅允许列明的来源域名，无法创建带特权的任意页面。Gemini 图片下载限制可信 Commons 图片域名、体积、超时和重定向次数。备份校验日期、结构、大小、危险原型字段和已知存储字段。

这些是防护措施，不是完成专业安全审计的声明。报告问题时请仅附脱敏复现步骤，勿公开真实密钥、完整私人备份或原稿。
