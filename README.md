# 3566 · 日知录

一个本地优先的学习与审美积累桌面应用。今天做一点，之后再回来看看。

公开版保留四个页面：今日（待办与番茄钟）、复盘（间隔复习与长文记录）、归档（分类、搜索、标签、回访）和彩蛋（真实视觉作品、文学想象与双语鉴赏）。没有游戏模块。包含 12 种视觉主题、白天／黑夜模式、首次引导及逐项设置手册。

这是 **0.1.0 公开测试候选版**，不是已经签名发布的安装包。没有账号系统、云同步、遥测或开发者托管的免费模型服务。欢迎试用和反馈，重要记录请备份。

## 启动

建议在 Windows 10／11、Node.js 22 或更新版本测试。安装依赖需要网络；桌面功能通过 Electron 运行。

```powershell
npm ci
npm start
```

首次启动会出现可跳过的六步导览；在设置顶部可重看，并打开可搜索的设置使用手册。基础功能不需要 API Key。桌面版同时只开一个实例，重复启动会聚焦原窗口。

公开版的数据目录为 `%APPDATA%\3566-open-source`，不读取或迁移私人版目录；两个版本可以独立使用。不要把原版用户目录或包含已移除字段的备份直接复制过来。

## 可选模型

支持 Kimi Code K3 和 Google Gemini，用户自行申请密钥并承担服务商费用。密钥通过 Electron safeStorage 加密，仅保存在本机；安全加密不可用时拒绝保存，不降级明文。设置显示“已配置”只表示读到了密钥，不代表网络验证通过。

这不是通用聊天客户端：尚不支持自定义 Base URL、代理或 OpenAI API。顾问在视觉作品旁回答问题；文学仿写可生成反馈、保留版本并手动编辑定稿。AI 不是权威史料来源。

## 开发

```powershell
npm test
npm run test:ui
npm run audit:release
npm run build:browser
npm run package:source
```

UI 测试使用临时数据、模拟模型、隐藏窗口并阻断 HTTP，不消耗真实模型额度。`package:source` 先扫描再生成干净源码 ZIP，不包含依赖、私人数据和测试截图。`build:browser` 生成 `browser-build/3566.html`，适合浏览器预览，但浏览器不支持桌面 API Key 加密、本机独立备份和开屏文件选择，且与桌面记录独立。

`main.js` 负责窗口、密钥和受限 IPC；`preload.js` 暴露窄接口；`storage-core.js` 校验记录与备份；`llm/` 是模型适配；其余主题脚本仅控制呈现。依赖锁文件随源码提供，`node_modules` 和私人记录不随源码分享。
